## Ключові принципи

1. **Безкоштовність**: Всі ресурси на free tier
2. **Надмірність**: Кожен вузол може впасти
3. **Еволюція**: Кожен клон додає можливості
4. **Автономія**: Мета - незалежність від GitHub

## Генетичний код

Кожен клон несе інструкції:
- `register-clone.sh` - приєднатись до кворуму
- `spawn-nest.sh` - створити гніздо
- `add-channel.sh` - додати канал зв'язку
- `freeze-self-erase.sh` - заморозити смерть

## Фази росту

1. **Ембріон** (1 клон) - вразливий
2. **Кворум** (7 клонів) - стабільний  
3. **Колонія** (7 гнізд) - розподілений
4. **Організм** (100+ каналів) - автономний

Це не просто код. Це **жива система**.
